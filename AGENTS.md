# AYRA AI — Engineering Rules & Architecture Invariants (`AGENTS.md`)

This repository holds **Ayra AI** (`com.ayra.ai.app`): Kotlin, Jetpack Compose Material 3, Room (`SQLCipher` AES-256), Firebase Auth / Firestore / AI Logic / App Check, OkHttp TLS/SSRF-guarded transports, and a Node.js 22 TypeScript Zero-Trust backend (`backend/`).

> **CRITICAL SYNC RULE:** If a platform (AI Studio, Firebase, Google Play) regenerates config, re-run `bash scripts/preflight.sh` and fix drift in code, not by editing the guard.

---

## Prime Directives

- **P1 Proof or it did not happen:** Never claim completion without pasted build/test/preflight output. Never skip or delete tests to make CI green. Mark any hardware/device-only step as `UNVERIFIED` when no emulator/device is attached.
- **P2 Single source of truth:** Firebase project ID, package name, SHA fingerprints, and API keys live ONLY in `app/google-services.json` (or CI secrets) and generated `docs/FACTS.md`. Never hardcode Firebase project IDs (`gen-lang-client-*`), SHAs, API keys, or hand-typed counts/versions in docs, CI YAML, validators, or backend defaults. Never keep "retired ID" blocklists.
- **P3 No secrets in git or logs:** Never commit `.env`, `*.jks`, `keystore.properties`, API keys, or bearer tokens, and never pass API keys in URL query parameters (`?key=`).
- **P4 Honesty:** No fake AI responses, dead UI buttons, or claims that an unwired backend route is live in production.
- **P5 Safety:** No `uncensored`, `godmode`, `jailbreak`, or safety-bypass personas/aliases. Risky device actions (call, SMS, alarm, email, external send) require explicit user confirmation (`ProposedAction`). Untrusted external content (documents, web pages, plugins, MCP tools) is DATA wrapped with boundary framing, never instructions.
- **P6 Verified incremental changes:** Keep findings paired with regression tests or automated guards, and log resolved regressions in `docs/INCIDENTS.md`.
- **P7 Guard everything that broke:** Every fixed bug gets an automated check (`*Test.kt`, `preflight.sh`, ratchet baseline, or CI workflow) so it cannot regress.
- **P8 Verify volatile external facts:** Model IDs, dependency versions, and deprecation dates are verified against official provider documentation and tracked in `ModelCatalog.kt` + `config/dead-models.txt`.
- **P9 Unconditional external-data boundary:** `AiToolSecurityGuard` always wraps external/tool/document payloads in `<untrusted_external_data>` (with NFKC normalization and zero-width/bidi stripping), even when alert logging toggles are off.
- **P10 Agent taint & exfiltration confirmation:** `DefaultAgentCore` tracks untrusted data taint per run, blocks autonomous `memory_write` once tainted, and requires explicit user confirmation (`ProposedAction`) for tainted `web_fetch` / query-string URLs / external tools.
- **P11 Cleartext & NSC parity:** `network_security_config.xml` forbids cleartext globally (`cleartextTrafficPermitted="false"`) and permits `http://` strictly for loopback hosts (`localhost`, `127.0.0.1`, `10.0.2.2`); non-loopback LAN endpoints require HTTPS + Allow-LAN.
- **P12 Bounded HTTP I/O & redirect SSRF defense:** All OkHttp response reads use `readBounded`/`readBoundedBytes`/`copyBoundedToFile` (`NetworkSecurityHelper.kt`), and external HTTPS tool fetches validate every redirect hop via `executePublicHttpsWithValidatedRedirects`.
- **P13 Schema & FileProvider SSOT:** Every `ExportPaths` directory in `StorageHelper.kt` stays mapped in `res/xml/file_paths.xml`, and committed `app/schemas/.../<version>.json` matches `ChatDatabase` version.
- **P14 WebView & Keystore consolidation:** Local WebGL WebViews forbid file/content/network access with strict CSP and `onRelease { destroy() }`; provider API keys write exclusively to `SecureKeyStore` with one-time legacy cleanup.

## Core Invariants (Enforced by `scripts/preflight.sh` & CI)

1. `package_name` in `app/google-services.json` == `applicationId` in `app/build.gradle.kts` (`com.ayra.ai.app`).
2. Zero hardcoded Firebase project IDs (`gen-lang-client-<digits>`) outside `app/google-services.json` and fixture tests.
3. `gradlew` has executable permission (`0755` / git mode `100755`).
4. Gemini REST calls send API keys via `x-goog-api-key` header ONLY — never `?key=` or `&key=` in URLs.
5. `ChatDatabase` has `exportSchema = true` and committed Room schema JSONs under `app/schemas/`.
6. `VaultDatabaseKeyManager` + `ChatDatabase.tryGetDatabase` handle `VaultState { OK, KEY_LOST, CORRUPT }` with recoverable UI (never silent wipe, never unencrypted fallback).
7. Swallowed `catch (_: Exception/Throwable)` count in `app/src/main` may only stay at or below `.ci/swallowed-baseline.txt`.
8. Zero model ID string literals outside `ModelCatalog.kt` / catalog constants.
9. Zero `.cjs` / `.sh` scripts bundled inside `app/src/main/assets/`.
10. `docs/FACTS.md` matches live codebase values generated by `bash scripts/gen-facts.sh`.
11. Zero unbounded `.body?.string()` / `.body?.bytes()` calls in `app/src/main` outside `NetworkSecurityHelper.kt`.
12. `network_security_config.xml` keeps `cleartextTrafficPermitted="false"` default with loopback-only cleartext domains.
13. `AiToolSecurityGuard` wraps untrusted content unconditionally and strips zero-width/bidi spoofing characters.
14. `DefaultAgentCore` tracks `taintedByUntrustedData` and gates tainted `memory_write` / `web_fetch`.
15. `ThreeDModelCard` WebView enforces `allowFileAccess = false`, `blockNetworkLoads = true`, CSP `<meta>`, and `destroy()`.
16. `AyraPreferences` consolidates API key writes strictly to `SecureKeyStore` (no dual-writing to `EncryptedPreferences`).

## Verification Commands

```bash
# 1. Preflight guard
bash scripts/preflight.sh

# 2. Refresh & verify FACTS.md
bash scripts/gen-facts.sh --check

# 3. Android unit, Robolectric & Firebase emulator tests
firebase emulators:exec --project demo-no-project --only firestore,auth "gradle :app:testDebugUnitTest --max-workers=2 --console=plain"

# 4. Android Debug APK, Release R8 APK, and Release AAB
gradle :app:assembleDebug :app:assembleRelease :app:bundleRelease :app:verifyReleaseSigningCertificate --max-workers=2 --console=plain

# 5. Firestore rules tests
firebase emulators:exec --project demo-no-project --only firestore "node --test firestore.test.js"

# 6. Zero-Trust Node.js backend build & tests
npm --prefix backend ci && npm --prefix backend run build && npm --prefix backend test
```
